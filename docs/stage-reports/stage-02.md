### Problems found and fixed during testing

1. **Build failed fetching Google Fonts.** Fonts are now bundled via the `geist` package, so builds and the running app never depend on Google.
2. **Type-check failed on a fresh checkout** (route types are generated by Next.js). Fixed by running `next typegen` first.
3. **Copied `use-mobile` hook failed a React lint rule.** Rewritten with `useSyncExternalStore`.
4. **Touch targets were 36 px**, below the 44 px requirement (NFR-USE-002). Enlarged on phones.

## Not tested (known limitations)

- **Docker image and compose files were not built or run**: Docker is installed in my workspace but its service is not running. They follow Next.js's standalone pattern but are unverified until built on your computer or server (Stage 15 at the latest).
- **Supabase connection not exercised**: there is no database yet (Stage 3). The clients compile and the app runs without Supabase configured.
- **Real devices not tested**: checks used a desktop Chrome browser at desktop and phone sizes. Real Android/iPhone testing belongs to Stage 14.
- **CI workflow not run on GitHub**: no repository connected yet.
- The deployment guide's Supabase service names (`kong`, `supavisor`) must be checked against the version you download.
- `npm audit` reports advisories in development dependencies; to be reviewed in Stage 15.

## Decisions taken in this stage

| Decision | Plain-language reason |
|---|---|
| Next.js 16 conventions kept: `proxy.ts` (formerly middleware) and Cache Components | Current defaults of the framework. Per-user content will load in its own section of the page so the rest appears instantly. |
| Active business remembered in a secure cookie, not the web address | Shorter addresses. Security still comes from database membership checks. |
| shadcn/ui components copied from shadcn's official GitHub repository | The shadcn website is blocked in my workspace; the code is identical. |
| Fonts bundled with the app | Works on a self-hosted server with no outside dependency. |
| Module menus driven by one registry | Disabled modules simply don't appear. Server and database blocking come in Stages 3–4. |
